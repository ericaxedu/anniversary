# Erica ♡ Josol — Clickable 4th Anniversary Gift

## How to open
1. Extract the ZIP.
2. Open `index.html` in Chrome/Safari/Edge.
3. On phone, you can open it from your Files app or upload the folder to a static hosting service.
4. Passcode: **1007**

## Mobile friendly
The gift is designed mobile-first for Android/iPhone and also adapts to desktop.

## Add your photos
The four memory cards are placeholders. If you want real photos, replace the placeholder buttons in `index.html` with `<img>` tags and add your images to an `assets` folder.

## Add your song
Put your MP3 at:
`assets/song.mp3`

The page already has a music player.

## Main navigation
This is intentionally NOT a long scrolling website. Each screen is a separate clickable page/state:
Secret Entry → Welcome → Story → Memories → Letter → Open When → LDR Chapter → Promises → Song → Until We Meet → Final Surprise.
